# Image Gallery

Browse ComfyUI output directory with lazy loading and metadata viewing.

## Overview

The Image Gallery node provides a comprehensive image browser for viewing ComfyUI-generated images directly in the workflow canvas, with real-time updates, metadata viewing, and search/sort capabilities.

## Features

- **Directory Browser**: Navigate ComfyUI output folder with breadcrumb navigation
- **Lazy Loading**: Efficiently loads images as you scroll
- **Full-Screen Preview**: Click images for large preview modal
- **Metadata Viewer**: Right-click to view PNG metadata (prompts, workflow)
- **Real-Time Updates**: Automatically refreshes when new images are generated
- **Search & Filter**: Find images by name with real-time filtering
- **Sort Options**: Sort by name, date modified, or date created
- **Resizable**: Adjust node size to fit your workspace

## UI Components

### Breadcrumb Navigation
- Current path display
- Click any segment to navigate to that folder
- "Output" button returns to root directory

### Toolbar
- **Auto-refresh Toggle**: Enable/disable automatic updates
- **Refresh Button**: Manually refresh gallery
- **Search Box**: Filter images by filename
- **Sort Dropdown**: Change sort order

### Gallery Grid
- Responsive grid layout
- Folder items (blue) listed first
- Image thumbnails with lazy loading
- Click to view full-size
- Right-click for metadata

## Features in Detail

### Lazy Loading
- Images load as you scroll
- Reduces initial load time
- Smooth scrolling experience
- Handles large image collections efficiently

### Full-Screen Preview
- Click any image to open full-size preview
- Click backdrop or close button to dismiss
- High-quality image display
- Preserves aspect ratio

### Metadata Viewer
1. Right-click any image
2. Select "View Metadata"
3. Modal displays:
   - ComfyUI prompt JSON
   - Workflow JSON
   - Image information (size, format)
   - File information (size, dates)
4. Click "Copy to Clipboard" to copy metadata
5. Expandable sections for easy navigation

### Auto-Refresh
- Automatically polls output directory every 2 seconds
- Detects when new images are added or removed
- Instantly updates gallery when changes are detected
- Minimal overhead - only checks file list, doesn't reload images
- Toggle on/off as needed

### Search & Sort

#### Search
- Type in search box
- Filters both folders and images
- Real-time filtering
- Case-insensitive

#### Sort Options
- **Name**: Alphabetical order
- **Date Modified**: Most recently modified first
- **Date Created**: Most recently created first

## Troubleshooting

### Images Not Showing
- Click refresh button
- Check ComfyUI output directory exists
- Verify images are in supported formats (.png, .jpg, .jpeg, .gif, .webp, .bmp)

### Auto-Refresh Not Working
- Ensure auto-refresh toggle is enabled (green button)
- Check browser console for "[Gallery] New images detected" messages
- Verify images are being saved to the output directory
- Try manual refresh button to verify API connectivity
- Auto-refresh checks every 2 seconds - there may be a brief delay
- If polling stops, try toggling auto-refresh off and on again

### Metadata Not Found
- Only PNG files contain ComfyUI metadata
- JPG/JPEG images only show basic info
- Ensure image was generated by ComfyUI with metadata saving enabled

### Performance Issues
- Large image collections load lazily (scroll to load more)
- Close other resource-intensive nodes
- Try searching/filtering to reduce displayed items

## Technical Details

- **Image Formats**: .png, .jpg, .jpeg, .gif, .webp, .bmp
- **Lazy Load Margin**: 50px (images load just before entering viewport)
- **Default Size**: 600x350 (resizable)
- **Grid Layout**: Responsive, minimum 150px columns
- **Auto-Refresh**: Polls directory every 2 seconds, compares file lists for changes
- **Performance**: Efficient change detection - only reloads when new images detected

## Security

- Path traversal protection: Cannot navigate outside output directory
- Server-side validation ensures safe file access
- Read-only: Cannot modify or delete images
